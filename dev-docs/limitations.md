# ข้อจำกัดที่ทราบของระบบ

รายการสิ่งที่ระบบทำไม่ได้หรือทำได้จำกัด ณ ตอนนี้ พร้อมสาเหตุ บันทึกไว้เพื่อไม่ต้องไล่หาซ้ำ
อัปเดตล่าสุด 2026-11-01

## 1. ขนาดไฟล์โมเดลต่อ environment

| ระบบ | ที่เก็บ | ขนาดสูงสุด | ติดอะไร |
| --- | --- | --- | --- |
| Docker | volume `model_files` (`MODEL_STORAGE=file`) | ไม่จำกัด | — |
| Vercel + Render | `modelData` ใน MongoDB | ประมาณ 4.5 MB | Vercel รับ body ของคำขอได้ไม่เกินประมาณ 4.5 MB (ตั้งค่าแก้ไม่ได้) และเอกสาร MongoDB ใหญ่ได้ไม่เกิน 16 MB |
| Azure | Azure Blob (กำลังทำ) | ไม่จำกัด | — |

หน้าอัปโหลดบอกเพดานของระบบนั้นตั้งแต่เลือกไฟล์ โมเดลใหญ่ (เช่น L) ให้อัปโหลดผ่าน Docker หรือ Azure

## 2. Render แบบฟรีรันโมเดลใหญ่ไม่ได้

| หัวข้อ | รายละเอียด |
| --- | --- |
| อาการ | ตั้งโมเดล L เป็นโมเดลหลักแล้ว Render ขึ้น `Instance … restarted` และเว็บแจ้ง "การประมวลผลรูปภาพขัดข้องที่ระบบ AI" |
| ติดอะไร | RAM 512 MB ไม่พอเปิดโมเดลขนาด 100 MB ขึ้นไป |
| วิธีเลี่ยง | ใช้โมเดลเล็ก (เช่น best.pt 5 MB) บน Vercel + Render ส่วนโมเดลใหญ่ใช้กับ Docker หรือ Azure |

## 3. การวิเคราะห์บน Render ช้ามาก

| หัวข้อ | รายละเอียด |
| --- | --- |
| อาการ | วิเคราะห์ 1 รูปใช้ 37–106 วินาที ขณะที่ Docker บนเครื่องทดสอบใช้ราว 0.2 วินาที |
| ติดอะไร | ทรัพยากรเครื่องของบริการ AI บน Render ไม่พอสำหรับรัน YOLO โค้ดและโมเดลเป็นชุดเดียวกัน |
| รายละเอียดตัวเลข | [performance/web.md](performance/web.md) |

## 4. ฟังก์ชันที่ยังไม่มี

| รายการ | ผลกระทบ |
| --- | --- |
| หน้าเปลี่ยนรหัสผ่าน | ต้องตั้งรหัสผ่านแอดมินเริ่มต้นก่อนเปิดระบบครั้งแรก |
| หน้าเปลี่ยนสิทธิ์ผู้ใช้ | ผู้ที่สมัครทีหลังเป็นผู้ใช้ทั่วไปเสมอ |
| ผู้ใช้ทั่วไปลบประวัติของตนเอง | ต้องให้ผู้ดูแลระบบลบให้ |

รายการที่ยังไม่ตรงกับขอบเขตในเล่มอยู่ใน [scope-traceability.md](scope-traceability.md)
