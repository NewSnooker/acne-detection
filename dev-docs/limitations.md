# ข้อจำกัดที่ทราบของระบบ

รายการสิ่งที่ระบบทำไม่ได้หรือทำได้จำกัด ณ ตอนนี้ พร้อมสาเหตุ บันทึกไว้เพื่อไม่ต้องไล่หาซ้ำ
อัปเดตล่าสุด 2026-10-31

## 1. อัปโหลดโมเดล AI บนเว็บที่ deploy บน Vercel ไม่ได้

| หัวข้อ | รายละเอียด |
| --- | --- |
| อาการ | กดบันทึกโมเดลในหน้า **จัดการโมเดล AI** แล้วไม่สำเร็จ ใน Console ขึ้น `413` |
| ติดอะไร | Vercel จำกัดขนาดคำขอที่ส่งเข้าฟังก์ชันไว้ประมาณ 4.5 MB ต่อครั้ง ไฟล์โมเดลของโครงงานมีขนาด 5.4 MB จึงถูก Vercel ปฏิเสธก่อนถึงโค้ดของระบบ |
| แก้ด้วยการตั้งค่าได้ไหม | ไม่ได้ เพดานนี้เป็นของผู้ให้บริการ |
| กระทบที่ไหน | เฉพาะเว็บบน Vercel — การอัปโหลดโมเดลด้วย Docker หรือรันในเครื่องทำได้ตามปกติ |
| สิ่งที่ยังทำได้บน Vercel | ใช้โมเดลที่มีอยู่ในฐานข้อมูลแล้ว วิเคราะห์รูป เปลี่ยนโมเดลหลัก แก้ไขข้อมูลโมเดล ลบโมเดล |
| วิธีเลี่ยง | อัปโหลดโมเดลผ่านระบบที่รันในเครื่องหรือ Docker โดยชี้ `DATABASE_URL` ไปที่ฐานข้อมูลเดียวกับเว็บบน Vercel |
| แนวทางถ้าจะแก้ในอนาคต | ให้เบราว์เซอร์ส่งไฟล์ขึ้น Vercel Blob โดยตรง แล้วเก็บเฉพาะที่อยู่ไฟล์ในฐานข้อมูล (เคยทดลองเขียนแล้ว ยังไม่ได้นำมาใช้) |

## 2. ขนาดไฟล์โมเดลสูงสุด

| ที่เก็บ | ขนาดสูงสุด | ใช้เมื่อ |
| --- | --- | --- |
| โฟลเดอร์ `MODEL_STORAGE_PATH` | ไม่จำกัด (เท่าที่ดิสก์มี) | Docker (ตั้งให้แล้ว) หรือตั้งค่าเองตอนรันในเครื่อง / Azure |
| MongoDB `AiModel.modelData` | 15 MB | ไม่ได้ตั้ง `MODEL_STORAGE_PATH` เช่นบน Vercel |

ไฟล์อัปโหลดแบบ stream ลงดิสก์ ไม่อ่านทั้งไฟล์เข้าหน่วยความจำ และ `/api/models` ไม่ผ่าน `proxy.ts` (proxy เก็บ body ไว้ในหน่วยความจำและตัดทิ้งเงียบ ๆ ที่ 10 MB)
อัปเดต 2026-10-31

## 3. การวิเคราะห์บน Render ช้ามาก

| หัวข้อ | รายละเอียด |
| --- | --- |
| อาการ | วิเคราะห์ 1 รูปใช้ 37–106 วินาที ขณะที่ Docker บนเครื่องทดสอบใช้ราว 0.2 วินาที |
| ติดอะไร | ทรัพยากรเครื่องของบริการ AI บน Render ไม่พอสำหรับรัน YOLO โค้ดและโมเดลเป็นชุดเดียวกัน |
| รายละเอียดตัวเลข | [performance/web.md](performance/web.md) |

## 4. ฟังก์ชันที่ยังไม่มี

| รายการ | ผลกระทบ |
| --- | --- |
| หน้าเปลี่ยนรหัสผ่าน | ต้องตั้งรหัสผ่านแอดมินเริ่มต้นก่อนเปิดระบบครั้งแรก |
| หน้าเปลี่ยนสิทธิ์ผู้ใช้ | ผู้ที่สมัครทีหลังเป็นผู้ใช้ทั่วไปเสมอ |
| ผู้ใช้ทั่วไปลบประวัติของตนเอง | ต้องให้ผู้ดูแลระบบลบให้ |

รายการที่ยังไม่ตรงกับขอบเขตในเล่มอยู่ใน [scope-traceability.md](scope-traceability.md)
