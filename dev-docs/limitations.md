# ข้อจำกัดที่ทราบของระบบ

รายการสิ่งที่ระบบทำไม่ได้หรือทำได้จำกัด ณ ตอนนี้ พร้อมสาเหตุ บันทึกไว้เพื่อไม่ต้องไล่หาซ้ำ
อัปเดตล่าสุด 2026-11-01

## 1. ขนาดไฟล์โมเดล (แก้แล้ว 2026-11-01)

อัปโหลดได้ไม่จำกัดขนาดทุก environment รวมถึง Vercel: เบราว์เซอร์ส่งไฟล์ทีละชิ้น 4 MB (ต่ำกว่าเพดาน 4.5 MB ของ Vercel) และเก็บแต่ละชิ้นเป็นเอกสารแยกใน MongoDB (ต่ำกว่าเพดาน 16 MB ต่อเอกสาร)

| ข้อควรรู้ | รายละเอียด |
| --- | --- |
| พื้นที่ฐานข้อมูล | MongoDB Atlas แบบฟรี (M0) มีพื้นที่รวม 512 MB — โมเดล L ราว 100–150 MB เก็บได้ไม่กี่ตัว ควรลบโมเดลที่ไม่ใช้ หน้าอัปโหลดบนเว็บที่ deploy จะเตือนเมื่อไฟล์เกิน 50 MB |
| บริการ AI | Render แบบฟรี (RAM 512 MB) อาจรันโมเดลใหญ่ไม่ไหว ต้องใช้เครื่องที่แรงกว่า (เช่น Azure) |
| โมเดลแบบเก่า | โมเดลที่เคยเก็บในโฟลเดอร์ `MODEL_STORAGE_PATH` อยู่บนดิสก์ของเครื่องที่อัปโหลดเท่านั้น ถ้าใช้ฐานข้อมูลร่วมกับเว็บที่ deploy และตั้งเป็นโมเดลหลัก เว็บที่ deploy จะวิเคราะห์ไม่ได้ (Render ตอบ 400) — ให้อัปโหลดใหม่เพื่อเก็บแบบหั่นชิ้น |

## 3. การวิเคราะห์บน Render ช้ามาก

| หัวข้อ | รายละเอียด |
| --- | --- |
| อาการ | วิเคราะห์ 1 รูปใช้ 37–106 วินาที ขณะที่ Docker บนเครื่องทดสอบใช้ราว 0.2 วินาที |
| ติดอะไร | ทรัพยากรเครื่องของบริการ AI บน Render ไม่พอสำหรับรัน YOLO โค้ดและโมเดลเป็นชุดเดียวกัน |
| รายละเอียดตัวเลข | [performance/web.md](performance/web.md) |

## 4. ฟังก์ชันที่ยังไม่มี

| รายการ | ผลกระทบ |
| --- | --- |
| หน้าเปลี่ยนรหัสผ่าน | ต้องตั้งรหัสผ่านแอดมินเริ่มต้นก่อนเปิดระบบครั้งแรก |
| หน้าเปลี่ยนสิทธิ์ผู้ใช้ | ผู้ที่สมัครทีหลังเป็นผู้ใช้ทั่วไปเสมอ |
| ผู้ใช้ทั่วไปลบประวัติของตนเอง | ต้องให้ผู้ดูแลระบบลบให้ |

รายการที่ยังไม่ตรงกับขอบเขตในเล่มอยู่ใน [scope-traceability.md](scope-traceability.md)
