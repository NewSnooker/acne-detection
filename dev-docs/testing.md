# ชุดทดสอบ

ทดสอบเฉพาะฟีเจอร์สำคัญ: ส่วนที่ถ้าพังแล้วกระทบผลวิเคราะห์ ความปลอดภัย หรือข้อมูลผู้ใช้
ทุกชุดรันได้โดยไม่ต้องเปิด Docker, MongoDB หรือโหลดโมเดลจริง

## วิธีรัน

```bash
# เว็บ (apps/web) — Vitest
npm install        # ครั้งแรก
npm test

# AI (apps/ai) — pytest
venv\Scripts\python.exe -m pip install -r requirements-dev.txt   # ครั้งแรก
venv\Scripts\python.exe -m pytest
```

ผลล่าสุด (2026-10-31): เว็บ 209 กรณีผ่าน, AI 48 กรณีผ่าน

GitHub Actions (`.github/workflows/ci.yml`) รันชุดเดียวกันนี้ทุก push เข้า `main` และทุก PR พร้อม `format:check`, `lint`, `typecheck` ฝั่งเว็บ

## วิธีที่ใช้

| ฝั่ง | เครื่องมือ | สิ่งที่จำลอง |
|---|---|---|
| เว็บ | Vitest | ฐานข้อมูล (`@/lib/prisma`), การเข้าสู่ระบบ (`@/lib/auth`), ที่เก็บรูป, บริการ AI |
| AI | pytest + FastAPI `TestClient` | `torch`, `ultralytics` และ `YoloService` (ดู `tests/conftest.py`) |

ไฟล์ทดสอบฝั่งเว็บวางไว้ข้างไฟล์ที่ทดสอบ ลงท้ายด้วย `.test.ts`

## สิ่งที่ชุดทดสอบนี้ไม่ครอบคลุม

- หน้าจอ ตาราง และกราฟ (ไม่มีการทดสอบแบบเปิดเบราว์เซอร์)
- ขั้นตอนฝั่ง Google จริง และการออกจากระบบ (เป็นโค้ดของ Auth.js)
- ความแม่นของโมเดล (Recall, F1, mAP) — เป็นผลจากช่วงเทรน ไม่ใช่การทดสอบโค้ด
- การทำงานร่วมกับ MongoDB, Vercel Blob และ YOLO ตัวจริง — ต้องทดสอบด้วยมือผ่าน Docker
- หน้าสถิติ (`server/statistics.ts`)
