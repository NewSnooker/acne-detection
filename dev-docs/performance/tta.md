# ผลทดสอบ Test-Time Augmentation (TTA)

วัดเมื่อ 2026-11-03 — สคริปต์ที่ใช้: `apps/ai/scripts/eval_tta.py` (รันบน Kaggle ซ้ำได้ทุกโมเดล)

## สรุป

**TTA ไม่ทำให้โมเดล L แม่นขึ้นบนชุดทดสอบ แต่ช้าลงประมาณ 2 เท่า → ปิดเป็นค่าเริ่มต้น** แอดมินเปิดได้รายโมเดล (`AiModel.useTta`, หน้า `/admin/models`)

## TTA ของ Ultralytics ทำอะไร

อ้างอิงโค้ด ultralytics 8.4.198 `nn/tasks.py` → `DetectionModel._predict_augment()`, `_descale_pred()`, `_clip_augmented()`, `utils/torch_utils.py` → `scale_img()`

1. ปรับภาพเป็นขนาดที่โมเดลใช้ (960) เหมือนการทำนายปกติ
2. ส่งภาพเข้าโมเดล 3 รอบ: ภาพเดิม 100% · ย่อ 83% + พลิกซ้าย-ขวา · ย่อ 67% (ภาพที่ย่อเติมขอบสีเทา 0.447 ให้เป็นทวีคูณของ 32)
3. แปลงพิกัดกรอบทุกรอบกลับเป็นของภาพต้นฉบับ (หารด้วยสัดส่วนที่ย่อ, รอบที่พลิก `x = กว้าง − x`)
4. ตัดผลที่ไม่น่าเชื่อ: ภาพ 100% ตัดผลชั้นหาวัตถุใหญ่, ภาพ 67% ตัดผลชั้นหาวัตถุเล็ก
5. รวมกรอบทั้ง 3 รอบ แล้วกรองด้วย `conf` + NMS ตามปกติ (เลือกกรอบที่มั่นใจที่สุด ไม่ได้เฉลี่ย)

คำนวณประมาณ 1 + 0.69 + 0.45 ≈ 2.1 เท่าของปกติ (ตามจำนวนพิกเซล) ตรงกับเวลาที่วัดได้

YOLO26 มีหัวทำนายแบบ NMS-free (end2end) ที่ไม่รองรับ TTA — ใน 8.4.198 ค่าเริ่มต้น `nms=None` ใช้หัวแบบปกติ + NMS จึงใช้ TTA ได้ (โค้ดในโปรเจคไม่ได้ตั้ง `nms`) ถ้าใครตั้ง `nms=False` TTA จะถูกข้ามพร้อมคำเตือน `does not support 'augment=True'`

## อ่านผล

- ใช้ชุด **test** สรุป เพราะไม่เคยใช้ระหว่างเทรน (valid ใช้เลือก best.pt จึงอาจได้เปรียบ)
- mAP@0.5 แทบไม่เปลี่ยน (ต่าง < 0.4 จุดทั้งสองชุด) — อยู่ในระดับคลาดเคลื่อนปกติ
- Det acc ลดลง ~3 จุด และ Precision ลด: TTA รวมกรอบจาก 3 รอบ ทำให้มีกรอบที่ไม่ใช่สิว (FP) มากขึ้น
- เวลาเพิ่ม ~2 เท่าบน GPU — บน CPU (Docker/Render) ใช้หน่วยความจำมากขึ้นด้วย

## ข้อความสำหรับเล่ม

> ผู้จัดทำทดลองใช้ Test-Time Augmentation (TTA) ของ Ultralytics ซึ่งนำภาพเข้าโมเดล 3 รอบ ได้แก่ ภาพเดิม ภาพย่อ 83% แบบพลิกซ้าย-ขวา และภาพย่อ 67% แล้วรวมกรอบทั้งหมดและคัดกรอบที่ซ้อนกันด้วย Non-Maximum Suppression เมื่อวัดกับโมเดล YOLO26-L บนชุดทดสอบ 1,444 ภาพที่ขนาดภาพ 960 พิกเซล พบว่า mAP@0.5 ลดลงจาก 57.61% เป็น 57.35% และ F1-score ลดลงจาก 60.80% เป็น 60.01% ขณะที่เวลาประมวลผลเพิ่มขึ้นจาก 88 เป็น 187 มิลลิวินาทีต่อภาพ (ประมาณ 2.1 เท่า) แม้บนชุดตรวจสอบ (validation) mAP@0.5 จะเพิ่มขึ้น 0.38% แต่ผลบนชุดทดสอบไม่ดีขึ้น และ Detection accuracy ลดลงประมาณ 3% เนื่องจากตรวจพบกรอบที่ไม่ใช่สิวมากขึ้น ระบบจึงไม่เปิดใช้ TTA เป็นค่าเริ่มต้น แต่ให้ผู้ดูแลระบบเลือกเปิดได้เป็นรายโมเดล

## วัดโมเดลอื่น

1. Kaggle notebook ใหม่ → วางเนื้อหา `apps/ai/scripts/eval_tta.py` ใน cell เดียว
2. แก้ `WEIGHTS_GLOB` ให้ชี้ไฟล์ `.pt` ของโมเดลนั้น และ `IMG` ให้ตรงกับขนาดที่เทรน
3. Add Input (csv + โมเดล), Secret `ROBOFLOW_API_KEY`, เปิด GPU + Internet
4. Save Version → Save & Run All → ผลอยู่ที่ Output `tta_eval/tta_compare.csv` และ confusion matrix ใน `tta_eval/<split>_tta0|1/`
5. เพิ่มแถวในไฟล์นี้
