## จัดการผู้ใช้

เมนู **จัดการผู้ใช้**

ตารางแสดง: ผู้ใช้งาน, อีเมล, สิทธิ์การใช้งาน, วันที่สมัคร, ประวัติการสแกน (จำนวนครั้ง)

| ทำอะไรได้ | วิธี |
| --- | --- |
| ค้นหา | พิมพ์ชื่อหรืออีเมลในช่องค้นหา |
| ลบผู้ใช้ 1 คน | กดปุ่ม **ลบบัญชีผู้ใช้** ในคอลัมน์ **จัดการ** แล้วยืนยัน |
| ลบหลายคน | ติ๊กเลือกแถวที่ต้องการ กด **ลบที่เลือก** แล้วยืนยัน |

**ข้อควรรู้**

- การลบผู้ใช้จะลบประวัติการสแกนและรูปของผู้ใช้นั้นทั้งหมด กู้คืนไม่ได้
- ผู้ดูแลระบบลบบัญชีของตัวเองไม่ได้

## จัดการโมเดล AI

เมนู **จัดการโมเดล AI**

ตารางแสดง: ชื่อโมเดล / ไฟล์, สถานะ (ใช้งานอยู่ / ไม่ได้ใช้), ขนาด, จำนวนครั้งที่ถูกใช้, วันที่อัปโหลด

**โมเดลหลัก** คือโมเดลที่ระบบใช้วิเคราะห์รูป มีได้ครั้งละ 1 ตัว

### เพิ่มโมเดล

1. กด **อัปโหลดโมเดล**
2. กดเลือกไฟล์ `.pt`
3. กรอก **ชื่อโมเดล** และ **เวอร์ชันโมเดล** (ระบบเติมให้จากชื่อไฟล์ แก้ได้) และ **รายละเอียด** ถ้ามี
4. กด **บันทึกโมเดล**

ถ้าระบบยังไม่มีโมเดลหลัก โมเดลที่อัปโหลดจะเป็นโมเดลหลักทันที ถ้ามีอยู่แล้ว โมเดลใหม่จะอยู่ในสถานะ **ไม่ได้ใช้**

### เปลี่ยนโมเดลหลัก

กดปุ่ม **ใช้งานโมเดล** ที่แถวของโมเดลที่ต้องการ แล้วกด **ยืนยัน** โมเดลหลักตัวเดิมจะถูกปิดอัตโนมัติ

การวิเคราะห์ครั้งแรกหลังเปลี่ยนโมเดลจะช้ากว่าปกติ เพราะบริการ AI ต้องโหลดโมเดลใหม่

### เปิดใช้ TTA (Test-Time Augmentation)

TTA ทำให้ระบบวิเคราะห์ภาพหลายขนาดและแบบพลิกภาพ แล้วรวมผลเข้าด้วยกัน ความแม่นยำไม่แน่นอน อาจเพิ่มหรือลดเล็กน้อยขึ้นอยู่กับโมเดล (โมเดลเริ่มต้นที่ทดสอบไว้ ผลบนชุดทดสอบลดลงเล็กน้อย) แต่วิเคราะห์ช้าลงประมาณ 2–3 เท่า และใช้ CPU/GPU และหน่วยความจำมากขึ้น เซิร์ฟเวอร์ที่ RAM น้อยอาจล่ม

- เปิด: กดปุ่ม **TTA** (รูปประกาย) ที่แถวของโมเดล อ่านคำเตือน แล้วกด **เปิดใช้ TTA** โมเดลจะมีป้าย **TTA** ในคอลัมน์สถานะ
- ปิด: กดปุ่มเดิมอีกครั้ง ปิดได้ทันทีไม่ต้องยืนยัน
- ตั้งแยกกันได้ทุกโมเดล มีผลเมื่อโมเดลนั้นเป็นโมเดลหลัก
- ผลที่วิเคราะห์แบบ TTA จะมีป้าย **TTA** ข้างชื่อโมเดลในหน้า **ประวัติการวิเคราะห์ทั้งหมด** (เห็นเฉพาะแอดมิน ผู้ใช้ทั่วไปไม่เห็น)
- ค่าประเมินในตาราง (และปุ่ม **ดึงจากไฟล์**) เป็นค่าที่วัดแบบไม่ใช้ TTA

### แก้ไข ลบ ค้นหา

| ทำอะไรได้ | วิธี |
| --- | --- |
| แก้ไขชื่อ เวอร์ชัน รายละเอียด และค่าประเมิน | กดปุ่ม **แก้ไขโมเดล** ที่แถวของโมเดล |
| ลบโมเดล 1 ตัว | กด **ลบโมเดล** แล้วกด **ลบทิ้งถาวร** |
| ลบหลายตัว | ติ๊กเลือก แล้วกด **ลบที่เลือก** |
| ค้นหา | พิมพ์ในช่องค้นหาเหนือตาราง |

**ค่าประเมินโมเดล**

ในหน้าต่างแก้ไขโมเดลมีช่อง mAP@0.5, Precision, Recall, F1-score และ Type Accuracy เป็นร้อยละ 0–100 (เว้นว่างได้)

- หลังอัปโหลดโมเดล ระบบอ่าน mAP@0.5, Precision, Recall จากผลเทรนที่ Ultralytics เก็บไว้ในไฟล์ `.pt` และคำนวณ F1-score ให้เองภายในไม่กี่วินาที
- โมเดลที่อัปโหลดไว้ก่อนแล้ว กดปุ่ม **ดึงค่าจากไฟล์โมเดล** ในหน้าต่างแก้ไข
- Type Accuracy ไม่มีในไฟล์ ต้องกรอกเอง — คือ "เมื่อพบสิวแล้ว บอกชนิดถูกกี่เปอร์เซ็นต์" = TP ÷ (TP + ทายผิดชนิด) จาก confusion matrix ของชุดทดสอบ (งานตรวจจับวัตถุไม่มี Accuracy แบบปกติ เพราะนับพื้นหลังที่ทายถูก (TN) ไม่ได้)
- ถ้าดึงค่าไม่ได้ ข้อความสีแดงจะบอกสาเหตุ เช่น key ไม่ตรงกัน หรือบริการ AI ยังเป็นรุ่นเก่า
- ถ้าขึ้นว่าไฟล์ไม่มีผลการเทรน (เช่นไฟล์ที่ export มาแบบตัดข้อมูลออก) ให้กรอกเองจากผลการทดสอบ

ค่าที่บันทึกแล้ว ค่าของโมเดลหลักจะแสดงในหน้าแรกของเว็บ และแสดงในคอลัมน์ **ค่าประเมิน (%)** ของตาราง

**ข้อควรรู้**

- ลบโมเดลหลักไม่ได้ ต้องเปลี่ยนโมเดลหลักไปเป็นตัวอื่นก่อน
- ประวัติการวิเคราะห์ที่เคยใช้โมเดลที่ถูกลบจะยังอยู่ แต่ไม่แสดงชื่อโมเดล
- ถ้าไม่มีโมเดลหลัก หน้าวิเคราะห์สิวจะขึ้น **ระบบไม่พร้อมใช้งาน**

## ไฟล์โมเดลที่ใช้ได้

| เงื่อนไข | รายละเอียด |
| --- | --- |
| ชนิดไฟล์ | `.pt` ที่ได้จากการเทรนด้วย Ultralytics YOLO (งาน Object Detection) |
| ขนาด | ขึ้นกับระบบที่ใช้ — Docker ไม่จำกัด (เช่นโมเดล L ราว 150 MB), เว็บบน Vercel ไม่เกินประมาณ 4.5 MB หน้าอัปโหลดบอกเพดานตั้งแต่เลือกไฟล์ และมีแถบความคืบหน้า |
| ที่ที่อัปโหลดได้ | อัปโหลดในระบบที่จะใช้โมเดลนั้น — แต่ละระบบ (Docker / เว็บบน Vercel / Azure) มีฐานข้อมูลและที่เก็บไฟล์ของตัวเอง ดูชื่อระบบได้จากป้ายบนหัวหน้า เช่น `DOCKER` `VERCEL` |
| จำนวนคลาส | 6 คลาส |
| ลำดับคลาส | ต้องเรียงตามตารางด้านล่าง |

| ลำดับ (index) | คลาส |
| --- | --- |
| 0 | blackhead |
| 1 | cyst |
| 2 | nodule |
| 3 | papule |
| 4 | pustule |
| 5 | whitehead |

ถ้าโมเดลเรียงคลาสต่างจากนี้ ระบบจะแสดงชื่อชนิดสิวผิด และระดับความรุนแรงจะผิดตาม

## ประวัติการวิเคราะห์ทั้งหมด

เมนู **ประวัติการวิเคราะห์ทั้งหมด** แสดงผลการตรวจของผู้ใช้ทุกคน

ใช้งานเหมือนหน้าประวัติของผู้ใช้ทั่วไป (สลับมุมมอง ค้นหา กรอง ดูรายละเอียด) และมีเพิ่ม:

| ทำอะไรได้ | วิธี |
| --- | --- |
| ดูว่าเป็นของผู้ใช้คนไหน | คอลัมน์ **ผู้ใช้งาน** ในมุมมองตาราง |
| ค้นหาตามผู้ใช้ | พิมพ์ชื่อหรืออีเมลในช่องค้นหา |
| ลบประวัติ 1 รายการ | มุมมองตาราง กด **ลบประวัตินี้** แล้วยืนยัน |
| ลบหลายรายการ | มุมมองตาราง ติ๊กเลือก แล้วกด **ลบที่เลือก** |

การลบประวัติจะลบรูปของรายการนั้นด้วย กู้คืนไม่ได้

## ภาพรวมระบบ

เมนู **ภาพรวมระบบ** เลือกช่วงเวลาได้จากตัวกรองด้านบน

| ส่วน | แสดงอะไร |
| --- | --- |
| ผู้ใช้งานหน้าใหม่ | จำนวนบัญชีที่สมัครในช่วงเวลาที่เลือก |
| การสแกนทั้งหมด | จำนวนครั้งที่มีการวิเคราะห์ |
| โมเดล | จำนวนโมเดลที่ถูกเพิ่ม |
| การเติบโตของฐานผู้ใช้งาน | ยอดผู้ใช้สะสม แยกผู้ใช้ใหม่กับผู้ใช้เดิม |
| สถิติการสแกนระบบรวม | จำนวนการสแกนรายวัน |
| อันดับผู้ใช้งาน | 10 อันดับผู้ใช้ที่สแกนบ่อยที่สุด |
| การวิเคราะห์ล่าสุด | 10 รายการล่าสุด |
| สัดส่วนผลการตรวจพบ | พบสิว เทียบกับ หน้าใส |
| สัดส่วนความรุนแรงรวม | เล็กน้อย / ปานกลาง / รุนแรง ทั้งระบบ |
| ประเภทสิวที่พบมากที่สุด | จำนวนสิวแต่ละชนิดทั้งระบบ |
