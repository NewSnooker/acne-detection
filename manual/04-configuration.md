## ไฟล์ตั้งค่ามี 2 ไฟล์

ทั้งสองไฟล์ **ไม่บังคับ** สร้างเฉพาะเมื่ออยากเปลี่ยนค่า

| ไฟล์ | ใช้ทำอะไร | วิธีสร้าง |
| --- | --- | --- |
| `.env` (ข้าง `docker-compose.yml`) | เปลี่ยนค่าเริ่มต้นของ Docker: port, รหัสลับ, บัญชีแอดมินเริ่มต้น | คัดลอกจาก `.env.example` |
| `apps/web/.env` | ใส่ค่าของ Google login | สร้างไฟล์ใหม่ ใส่ 2 บรรทัดตามหัวข้อ [เปิด Google login](#google) |

หลังแก้ไฟล์ตั้งค่าทุกครั้ง ให้สั่ง `docker compose up -d` เพื่อให้ค่าใหม่มีผล

<a id="values"></a>

## ค่าที่เปลี่ยนได้

ใส่ในไฟล์ `.env` ข้าง `docker-compose.yml`

| ชื่อ | ค่าเริ่มต้น | ใช้ทำอะไร |
| --- | --- | --- |
| `WEB_PORT` | `3000` | port ของเว็บบนเครื่อง |
| `MONGO_PORT` | `27018` | port ของฐานข้อมูลใน Docker ที่เปิดออกมาบนเครื่อง เข้าได้เฉพาะเครื่องนี้ (ไม่ชนกับ MongoDB ที่ติดตั้งในเครื่องซึ่งใช้ 27017) |
| `AUTH_SECRET` | `acne-local-docker-secret-change-me` | รหัสลับสำหรับเข้ารหัสการเข้าสู่ระบบ |
| `AI_SERVICE_API_KEY` | `acne-local-docker-key` | รหัสที่เว็บใช้เรียกบริการ AI ระบบใส่ค่าเดียวกันให้ทั้งสองฝั่งเอง |
| `SEED_ADMIN_EMAIL` | `admin@acne.local` | อีเมลของแอดมินเริ่มต้น |
| `SEED_ADMIN_PASSWORD` | `Admin1234` | รหัสผ่านของแอดมินเริ่มต้น |

> ค่าเริ่มต้นสองตัวนี้ใช้กับ Docker บนเครื่องเท่านั้น ถ้า `DATABASE_URL` เป็น MongoDB Atlas (`mongodb+srv://`) แต่ไม่ได้ตั้งทั้งสองตัว ระบบ**จะไม่สร้างแอดมินเริ่มต้น** — สมัครสมาชิกผ่านหน้าเว็บ แล้วแก้ `role` เป็น `ADMIN` ในฐานข้อมูลเอง

<a id="port"></a>

## เปลี่ยน port ของเว็บ

ใช้เมื่อ port 3000 ถูกโปรแกรมอื่นใช้อยู่

1. สร้างไฟล์ `.env` ข้าง `docker-compose.yml` ใส่บรรทัดนี้

   ```
   WEB_PORT=3001
   ```

2. สั่ง `docker compose up -d`
3. เปิด <http://localhost:3001>

<a id="admin"></a>

## เปลี่ยนบัญชีแอดมินเริ่มต้น

ระบบสร้างแอดมินเริ่มต้นให้ **เฉพาะตอนที่ฐานข้อมูลยังไม่มีผู้ดูแลระบบ** จึงต้องตั้งค่าก่อนเปิดระบบครั้งแรก

1. สร้างไฟล์ `.env` ข้าง `docker-compose.yml`

   ```
   SEED_ADMIN_EMAIL=you@example.com
   SEED_ADMIN_PASSWORD=YourPassword123
   ```

2. สั่ง `docker compose up --build`

**ถ้าเปิดระบบไปแล้ว** ค่าใหม่จะไม่มีผล เพราะมีแอดมินอยู่แล้ว และระบบยังไม่มีหน้าเปลี่ยนรหัสผ่าน ทางเดียวคือล้างข้อมูลแล้วเริ่มใหม่:

```bash
docker compose down -v
docker compose up --build
```

> `docker compose down -v` ลบผู้ใช้ ประวัติ และโมเดลทั้งหมด กู้คืนไม่ได้

<a id="google"></a>

## เปิด Google login

ถ้าไม่ตั้งค่า ปุ่ม **Google** ในหน้าเข้าสู่ระบบจะขึ้นข้อความว่ายังไม่ได้ตั้งค่า ส่วนอื่นของระบบใช้ได้ตามปกติ

**ขั้นที่ 1 สร้าง OAuth Client ที่ Google**

1. เปิด [Google Cloud Console](https://console.cloud.google.com/) แล้วสร้างโปรเจค (หรือเลือกโปรเจคที่มีอยู่)
2. ไปที่ **APIs & Services → Credentials**
3. กด **Create Credentials → OAuth client ID** เลือกชนิด **Web application**
4. ที่ **Authorized redirect URIs** เพิ่ม

   ```
   http://localhost:3000/api/auth/callback/google
   ```

   ถ้าเปลี่ยน port หรือใช้ชื่อโดเมนอื่น ให้แก้ส่วนหน้า `/api/auth/...` ให้ตรงกับที่อยู่ที่ใช้เปิดเว็บ

5. กดสร้าง แล้วคัดลอก **Client ID** และ **Client secret**

**ขั้นที่ 2 ใส่ค่าในระบบ**

สร้างไฟล์ `apps/web/.env` ใส่ 2 บรรทัด

```
GOOGLE_CLIENT_ID=ค่า Client ID
GOOGLE_CLIENT_SECRET=ค่า Client secret
```

**ขั้นที่ 3 เปิดระบบใหม่**

```bash
docker compose up -d
```

**ข้อควรรู้**

- ต้องมีครบทั้งสองค่า ถ้าขาดค่าใดค่าหนึ่ง ระบบถือว่ายังไม่ได้ตั้งค่า
- ผู้ที่เข้าด้วย Google ครั้งแรกจะได้สิทธิ์ผู้ใช้ทั่วไป
- อีเมลที่สมัครด้วยรหัสผ่านไว้แล้ว ใช้ปุ่ม Google กับอีเมลเดียวกันไม่ได้

<a id="branding"></a>

## เปลี่ยนชื่อ สโลแกน และโลโก้

แก้ที่ไฟล์เดียว `apps/web/src/config/site.ts` แล้วจะเปลี่ยนทั้งเว็บ (sidebar, หน้าเข้าสู่ระบบ, header/footer หน้าแรก, ชื่อแท็บเบราว์เซอร์, favicon และรูปตอนแชร์ลิงก์)

| ค่า | ใช้ทำอะไร |
| --- | --- |
| `name`, `nameAccent` | ชื่อระบบ และส่วนท้ายของชื่อที่แสดงเป็นสีหลัก (เช่น Acne**AI**) |
| `tagline` | สโลแกนใต้ชื่อ |
| `logo` | ไฟล์รูปใน `apps/web/public/` ใช้เป็นโลโก้ favicon และรูปตอนแชร์ลิงก์ (รูปเดียวกัน) |
| `demoVideo` | วิดีโอเดโมใต้ภาพหลัก วางไฟล์ไว้ใน `apps/web/public/landing/` แล้วใส่ที่อยู่ไฟล์ `mp4` (และ `webm` ถ้ามี) กับภาพปก `poster` ถ้าเป็น `null` ส่วนนี้จะซ่อน |
| `hero` | ภาพหลักหน้าแรก (ภาพวาดประกอบ แสดงในกรอบ 4:3) ถ้าเปลี่ยนรูป ต้องแก้กรอบสิวตัวอย่างใน `components/knowledge/acne-samples.ts` ให้ตรงด้วย (หน่วย % ของกรอบ 4:3) |

ธีมสีอยู่ใน `apps/web/src/app/globals.css` (`--brand-*` และ `[data-palette]`) รายชื่อธีมอยู่ใน `apps/web/src/lib/theme/palettes.ts`

<a id="before-sharing"></a>

## ก่อนเปิดให้คนอื่นเข้าใช้

ค่าเริ่มต้นออกแบบมาสำหรับลองใช้บนเครื่องตัวเอง ถ้าจะเปิดให้คนอื่นเข้าผ่านเครือข่าย ควรเปลี่ยนค่าเหล่านี้ในไฟล์ `.env` **ก่อนเปิดระบบครั้งแรก**

| ค่า | เหตุผล |
| --- | --- |
| `SEED_ADMIN_PASSWORD` | รหัสผ่านเริ่มต้นเขียนอยู่ในคู่มือนี้ ใครก็รู้ |
| `AUTH_SECRET` | ค่าเริ่มต้นเปิดเผยอยู่ในโค้ด ควรใช้ค่าสุ่มยาว ๆ ของตัวเอง |
| `AI_SERVICE_API_KEY` | เช่นเดียวกัน |
