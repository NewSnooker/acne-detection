## สิ่งที่ต้องมี

| สิ่งที่ต้องมี | หมายเหตุ |
| --- | --- |
| [Docker Desktop](https://www.docker.com/products/docker-desktop/) | ต้องเปิดโปรแกรมค้างไว้ระหว่างใช้งาน ใช้ Docker Compose รุ่น 2.24 ขึ้นไป |
| [Git](https://git-scm.com/downloads) | ใช้โหลดโปรแกรม (หรือโหลดเป็นไฟล์ ZIP แทนก็ได้) |
| อินเทอร์เน็ต | ใช้ตอนเปิดครั้งแรกเพื่อดาวน์โหลดส่วนประกอบ |
| พื้นที่ว่างในเครื่อง | หลาย GB สำหรับ image ของ Docker |

ไม่ต้องติดตั้ง Node.js, Python หรือ MongoDB เอง ทุกอย่างอยู่ใน Docker

<a id="download"></a>

## ขั้นที่ 1 โหลดโปรแกรม

**วิธีที่ 1: ใช้ Git**

```bash
git clone https://github.com/NewSnooker/acne-detection.git
cd acne-detection
```

**วิธีที่ 2: โหลดเป็น ZIP**

1. เปิดหน้า GitHub ของโปรเจค
2. กดปุ่ม **Code** แล้วเลือก **Download ZIP**
3. แตกไฟล์ แล้วเปิด Terminal (หรือ PowerShell) ในโฟลเดอร์ที่แตกออกมา

> ถ้าโปรเจคยังตั้งเป็น private จะโหลดได้เฉพาะคนที่เจ้าของโปรเจคให้สิทธิ์

<a id="start"></a>

## ขั้นที่ 2 เปิดระบบ

เปิด Docker Desktop ให้เรียบร้อยก่อน แล้วสั่งในโฟลเดอร์โปรเจค:

```bash
docker compose up --build
```

**สิ่งที่จะเกิดขึ้น**

1. Docker สร้าง image ของเว็บและ AI — ครั้งแรกใช้เวลาหลายนาที เพราะต้องดาวน์โหลด PyTorch
2. เปิดฐานข้อมูล MongoDB และรอจนพร้อม
3. เว็บสร้างบัญชีผู้ดูแลระบบเริ่มต้น และใส่โมเดล AI เริ่มต้นลงฐานข้อมูล
4. เว็บพร้อมใช้งาน

**รู้ได้อย่างไรว่าพร้อมแล้ว**

ดู log ที่ขึ้นต้นด้วย `acne_web` จะมีบรรทัดประมาณนี้:

```
acne_web  | [seed] สร้างบัญชีแอดมินเริ่มต้น: admin@acne.local
acne_web  | [seed] ใส่โมเดลเริ่มต้นแล้ว (5.15 MB)
acne_web  |  ✓ Ready in ...
```

เมื่อเห็นคำว่า `Ready` ให้เปิด <http://localhost:3000>

ไม่ต้องสร้างไฟล์ `.env` ถ้าอยากเปลี่ยนค่า เช่น port หรือรหัสผ่านแอดมิน ดู [การตั้งค่า](04-configuration.md)

<a id="first-login"></a>

## ขั้นที่ 3 เข้าใช้งานครั้งแรก

1. เปิด <http://localhost:3000> จะเข้าหน้า **เข้าสู่ระบบ**
2. เข้าด้วยบัญชีผู้ดูแลระบบเริ่มต้น

   | อีเมล | รหัสผ่าน |
   | --- | --- |
   | `admin@acne.local` | `Admin1234` |

3. ไปที่เมนู **วิเคราะห์สิวด้วย AI** อัปโหลดภาพถ่ายใบหน้า แล้วกด **วิเคราะห์รูปภาพ**

การวิเคราะห์ครั้งแรกจะช้ากว่าปกติ เพราะ AI ต้องโหลดโมเดลเข้าหน่วยความจำก่อน ครั้งต่อไปจะเร็วขึ้น

**ข้อควรรู้**

- ผู้ใช้ทั่วไปสมัครเองได้ที่ลิงก์ **สมัครสมาชิก** ในหน้าเข้าสู่ระบบ
- ปุ่ม **Google** จะใช้ได้เมื่อตั้งค่าแล้วเท่านั้น ถ้ายังไม่ตั้งค่า กดแล้วจะขึ้นข้อความแจ้ง ดู [เปิด Google login](04-configuration.md#google)
- ระบบยังไม่มีหน้าเปลี่ยนรหัสผ่าน ถ้าต้องการรหัสผ่านแอดมินแบบอื่น ให้ตั้งก่อนเปิดระบบครั้งแรก ดู [เปลี่ยนบัญชีแอดมินเริ่มต้น](04-configuration.md#admin)

<a id="commands"></a>

## คำสั่งที่ใช้ประจำ

สั่งในโฟลเดอร์โปรเจคทุกครั้ง

| ต้องการ | คำสั่ง |
| --- | --- |
| เปิดระบบ (เห็น log) | `docker compose up` |
| เปิดระบบแบบทำงานเบื้องหลัง | `docker compose up -d` |
| ดู log | `docker compose logs -f` |
| ดู log เฉพาะเว็บ / AI | `docker compose logs -f web` / `docker compose logs -f ai` |
| หยุดระบบ (ข้อมูลยังอยู่) | `docker compose down` |
| อัปเดตเป็นโค้ดล่าสุด | `git pull` แล้ว `docker compose up --build` |
| ล้างข้อมูลทั้งหมด เริ่มใหม่ | `docker compose down -v` |

> `docker compose down -v` ลบฐานข้อมูลทั้งหมด (ผู้ใช้ ประวัติ โมเดล) กู้คืนไม่ได้

<a id="data"></a>

## ข้อมูลถูกเก็บไว้ที่ไหน

| ข้อมูล | ที่เก็บ | หายเมื่อ |
| --- | --- | --- |
| ผู้ใช้ ประวัติการวิเคราะห์ โมเดล AI | Docker volume `mongodb_data` | สั่ง `docker compose down -v` |
| รูปที่ผู้ใช้อัปโหลด | โฟลเดอร์ `apps/images/` | ลบไฟล์ในโฟลเดอร์นี้ |
| ไฟล์โมเดลที่ AI โหลดมาพักไว้ | โฟลเดอร์ `apps/ai/models/` | ลบได้ ระบบจะโหลดใหม่เอง |

ถ้าลบรูปใน `apps/images/` เอง ประวัติจะยังอยู่แต่รูปจะไม่แสดง ดู [แก้ปัญหา](05-troubleshooting.md#image-missing)
