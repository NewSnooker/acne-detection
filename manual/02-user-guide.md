## หน้าแรก

- **หน้าแรก** (`/`) เปิดได้โดยไม่ต้องเข้าสู่ระบบ ทุกอย่างอยู่ในหน้าเดียว เมนูด้านบนจะเลื่อนไปแต่ละหัวข้อ
  - **วิธีใช้งาน** 3 ขั้นตอน
  - **ดูแลผิว** คำแนะนำดูแลผิวแบบองค์รวม (การนอน ความเครียด อาหาร) การดูแลผิวพื้นฐาน และสาเหตุของสิว
  - **ชนิดของสิว** ภาพตัวอย่างสิว 6 ชนิดพร้อมกรอบสีและวิธีดูแล
  - **ความแม่นยำ** ค่าของโมเดลที่ใช้งานอยู่ (mAP, Precision, Recall, F1-score, Accuracy) และเกณฑ์ความรุนแรง 3 ระดับ ตัวเลขเปลี่ยนตามโมเดลที่แอดมินเปิดใช้งานในหน้าจัดการโมเดล
  - **เมื่อไรควรพบแพทย์** และ **คำถามที่พบบ่อย**

**ธีมสีและโหมดมืด:** ทุกหน้ามีปุ่มรูปจานสี (เลือกธีมสี 5 ชุด: ฟ้าเป็นค่าเริ่มต้น, ชมพูโรส, เขียวมิ้นต์, ม่วงลาเวนเดอร์, ส้มพีช) และปุ่มพระจันทร์/พระอาทิตย์ (สลับโหมดสว่าง/มืด) เบราว์เซอร์จะจำค่าที่เลือกไว้

ภาพตัวอย่างมาจากชุดข้อมูลบน Roboflow Universe สัญญาอนุญาต CC BY 4.0: ภาพหลักจาก [acne](https://universe.roboflow.com/-mqoyk/acne-ygqhs-w99jc) และภาพสิว 6 ชนิดจาก [Acne14k](https://universe.roboflow.com/s-workspace-fmu4q/acne-dataset-6-classes-ubwa5) (ตีกรอบครบทุกจุดตาม label ของชุดข้อมูล)

## สมัครสมาชิกและเข้าสู่ระบบ

**สมัครสมาชิก**

1. เปิดหน้าเข้าสู่ระบบ แล้วกด **สมัครสมาชิก**
2. กรอกข้อมูล

   | ช่อง | เงื่อนไข |
   | --- | --- |
   | ชื่อ - นามสกุล | 5–20 ตัวอักษร |
   | อีเมล | รูปแบบอีเมลที่ถูกต้อง และยังไม่เคยใช้สมัคร |
   | รหัสผ่าน | 8–20 ตัวอักษร มีตัวพิมพ์เล็กและตัวเลขอย่างน้อยอย่างละ 1 ตัว |
   | ยืนยันรหัสผ่าน | ต้องตรงกับรหัสผ่าน |

3. กด **สมัครสมาชิก** ระบบจะพากลับไปหน้าเข้าสู่ระบบพร้อมข้อความ "สมัครสมาชิกสำเร็จ"

**เข้าสู่ระบบ**

- ด้วยอีเมลและรหัสผ่าน: กรอกแล้วกด **เข้าสู่ระบบ**
- ด้วย Google: กดปุ่ม **Google** (ใช้ได้เมื่อผู้ติดตั้งระบบตั้งค่าไว้แล้ว)

อีเมลที่สมัครด้วยรหัสผ่านไว้แล้ว ต้องเข้าด้วยรหัสผ่าน ใช้ปุ่ม Google กับอีเมลเดียวกันไม่ได้

**ออกจากระบบ**

กดชื่อผู้ใช้ที่มุมขวาบน แล้วเลือก **ออกจากระบบ**

<a id="analyze"></a>

## วิเคราะห์สิว

1. ไปที่เมนู **วิเคราะห์สิวด้วย AI** ครั้งแรกจะมีป๊อปอัป **ก่อนเริ่มวิเคราะห์: ดูแลผิวแบบองค์รวม** สรุปเรื่องการนอน ความเครียด และอาหาร กด ✕ หรือ **เริ่มวิเคราะห์เลย** เพื่อปิด (ครั้งต่อไปจะไม่เด้งขึ้นอีก กด **คำแนะนำก่อนเริ่ม** ที่หัวหน้าเพื่อเปิดดูใหม่) หรือกด **อ่านเพิ่มเติม** เพื่อไปหน้าความรู้
2. ลากรูปมาวางในกรอบ หรือกด **เลือกไฟล์** (รองรับ JPEG และ PNG ขนาดไม่เกิน 10 MB ไฟล์ชนิดอื่นระบบจะแจ้งเตือนและไม่รับ)
3. ตรวจรูปตัวอย่าง ถ้าเลือกผิด กดปุ่มวงกลมมุมขวาบนของรูปเพื่อเปลี่ยนรูป
4. กด **วิเคราะห์รูปภาพ** แล้วรอจนแถบความคืบหน้าเต็ม
5. ผลจะแสดงทันที และถูกบันทึกลงประวัติอัตโนมัติ
6. กด **อัปโหลดรูปภาพใหม่** เพื่อวิเคราะห์รูปถัดไป

ถ้าหน้าจอขึ้น **ระบบไม่พร้อมใช้งาน** แปลว่ายังไม่มีโมเดล AI ที่เปิดใช้งาน ให้แจ้งผู้ดูแลระบบ

<a id="result"></a>

## อ่านผลการวิเคราะห์

**ภาพผลลัพธ์** — แต่ละจุดที่ตรวจพบจะมีกรอบสี่เหลี่ยมพร้อมชื่อชนิดสิว สีของกรอบบอกชนิด

| สีกรอบ | ชนิดสิว | ชื่อบนกรอบ |
| --- | --- | --- |
| เทา | สิวหัวดำ | blackhead |
| เทาอ่อน | สิวหัวขาว | whitehead |
| แดง | สิวตุ่มแดง | papule |
| เหลือง | สิวหัวหนอง | pustule |
| แดงเข้ม | สิวก้อนแข็ง | nodule |
| แดงเลือดหมู | สิวซีสต์ | cyst |

**แผงสรุปด้านขวา**

| ส่วน | ความหมาย |
| --- | --- |
| พบสิวทั้งหมด | จำนวนจุดที่ตรวจพบรวมทุกชนิด |
| ระดับความรุนแรง | เล็กน้อย / ปานกลาง / รุนแรง |
| สรุปตามประเภทสิว | จำนวนจุดแยกตามชนิด |
| คำแนะนำการดูแลผิว | คำแนะนำตามระดับความรุนแรง |

ถ้าไม่พบสิวเลย จะขึ้นข้อความว่าผิวหน้าดูสุขภาพดี

<a id="severity"></a>

## ระดับความรุนแรงและคำแนะนำ

ระบบประเมินจาก **ชนิด** และ **จำนวน** ของสิวร่วมกัน

| กลุ่ม | ชนิดสิว |
| --- | --- |
| ไม่อักเสบ | สิวหัวดำ, สิวหัวขาว |
| อักเสบระดับตื้น | สิวตุ่มแดง, สิวหัวหนอง |
| อักเสบระดับลึก | สิวก้อนแข็ง, สิวซีสต์ |

| ระดับ | เกณฑ์ | คำแนะนำโดยสรุป |
| --- | --- | --- |
| เล็กน้อย (Mild) | สิวไม่อักเสบไม่เกิน 20 จุด และสิวอักเสบระดับตื้นไม่เกิน 5 จุด | ดูแลความสะอาดผิวหน้า พิจารณาใช้เวชสำอางขั้นพื้นฐาน |
| ปานกลาง (Moderate) | สิวไม่อักเสบมากกว่า 20 จุด หรือสิวอักเสบระดับตื้น 6–20 จุด | ปรับพฤติกรรมการดูแลผิว และปรึกษาเภสัชกร |
| รุนแรง (Severe) | สิวอักเสบระดับตื้นมากกว่า 20 จุด หรือพบสิวอักเสบระดับลึกตั้งแต่ 1 จุด | เสี่ยงเกิดแผลเป็น ควรพบแพทย์ผิวหนัง |

<a id="history"></a>

## ประวัติการวิเคราะห์

เมนู **ประวัติการวิเคราะห์** แสดงผลการตรวจย้อนหลังทั้งหมดของคุณ

| ทำอะไรได้ | วิธี |
| --- | --- |
| สลับมุมมอง | กด **แบบการ์ด** หรือ **แบบตาราง** |
| ค้นหา | พิมพ์ในช่อง **ค้นหารายการ** เช่น ชนิดสิว (ภาษาอังกฤษ) ระดับความรุนแรง หรือวันที่ (เช่น 04/10/2026) |
| กรอง | กด **ตัวกรอง** เพื่อเลือกชนิดสิวที่ต้องการดู |
| ดูรายละเอียด | กดที่รายการ จะเปิดภาพผลลัพธ์พร้อมสรุป กดลูกศรซ้ายขวาเพื่อดูรายการก่อนหน้าหรือถัดไป |
| ล้างเงื่อนไข | กด **ล้างตัวกรองทั้งหมด** |

ผู้ใช้ทั่วไปลบประวัติเองไม่ได้ ถ้าต้องการลบให้แจ้งผู้ดูแลระบบ

<a id="overview"></a>

## ภาพรวมของฉัน

เมนู **ภาพรวมของฉัน** สรุปสถิติจากประวัติการตรวจของคุณ

| ส่วน | แสดงอะไร |
| --- | --- |
| การสแกนทั้งหมด | จำนวนครั้งที่วิเคราะห์ |
| จำนวนครั้งที่หน้าใส | จำนวนครั้งที่สแกนแล้วไม่พบสิว |
| ระดับความรุนแรงที่พบบ่อย | ระดับที่พบมากที่สุดในช่วงเวลาที่เลือก |
| กราฟจำนวนสิวทั้งหมด | จำนวนสิวที่พบในการสแกนแต่ละครั้ง |
| แผนภูมิสัดส่วน | สลับดูได้ระหว่าง **ระดับความรุนแรง** และ **ประเภทสิว** |

เลือกช่วงเวลาได้จากตัวกรองด้านบน: ทั้งหมด, วันนี้, 7 วันล่าสุด, รายเดือน, รายปี หรือระบุช่วงเวลาเอง

<a id="photo-tips"></a>

## ถ่ายรูปอย่างไรให้ผลแม่น

- ถ่ายในที่แสงสว่างสม่ำเสมอ ไม่ย้อนแสง ไม่มีเงาบนใบหน้า
- ถ่ายหน้าตรง ให้ใบหน้าอยู่เต็มภาพ
- ไม่ใช้ฟิลเตอร์หรือโหมดหน้าเนียน
- ไม่แต่งหน้าปกปิดสิว
- ใช้ภาพที่คมชัด ไม่เบลอ

<a id="limits"></a>

## ข้อจำกัดของระบบ

- ผลที่ได้เป็นการคัดกรองเบื้องต้น ไม่สามารถทดแทนการวินิจฉัยของแพทย์ผิวหนังได้
- ความแม่นยำขึ้นกับคุณภาพและปริมาณของชุดข้อมูลที่ใช้ฝึกโมเดล
- แสง มุมกล้อง และความละเอียดของภาพมีผลต่อผลลัพธ์
